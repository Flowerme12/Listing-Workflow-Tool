# ListingFlow

Private Internal Listing Management Tool

## Project Overview

ListingFlow is a private internal tool designed to manage draft listings for the Etsy shop owned and authorized by the application owner.

The application uses the official Etsy Open API v3 and OAuth 2.0 to securely manage the shop owner's listing workflow.

## Features

- **Draft Listing Management:** Creates and updates draft listings using owner-prepared listing data.

- **Product Image Upload:** Uploads product images created and owned by the shop owner.

- **Listing Data Management:** Manages titles, descriptions, tags, pricing, inventory, and SKU information.

- **API Usage:** Uses only the official Etsy Open API v3 and respects Etsy API rate limits.

## Usage & Privacy

ListingFlow is a private internal tool used only for the Etsy shop owned by the application owner.

It is not a commercial SaaS application and is not available to other Etsy sellers.

The application does not scrape Etsy webpages, collect competitor listing data, access third-party seller data, automate buyer activity, or manipulate views, favorites, reviews, or other engagement metrics.

Etsy API access is performed through the official Etsy Open API v3 and OAuth 2.0.

API credentials and OAuth tokens are stored securely and are not shared or transferred to third parties.
